# GuardianWheel

AI-Powered Driver Fatigue Detection and Real-Time Driver Assistance Platform

## Overview

GuardianWheel is an intelligent transportation safety platform that combines real-time driver fatigue detection with an on-demand replacement driver booking system.

The system monitors driver alertness using computer vision techniques such as Eye Aspect Ratio (EAR) and PERCLOS. When fatigue is detected, the platform alerts the driver and recommends nearby verified replacement drivers.

## Features

* Driver Fatigue Detection
* EAR & PERCLOS Monitoring
* Real-Time Alerts
* Driver Booking
* GPS Tracking
* SOS Emergency Support
* User Dashboard
* Driver Dashboard
* Firebase Authentication
