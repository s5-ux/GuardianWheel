# GuardianWheel Features

## AI-Based Fatigue Detection

Detects drowsiness using facial landmarks, EAR, and PERCLOS.

## Real-Time Monitoring

Continuous monitoring while driving.

## Driver Replacement Service

Provides verified replacement drivers during fatigue events.

## GPS Tracking

Tracks driver and user location in real time.

## SOS Emergency Support

Instant emergency assistance with location sharing.

## Driver Verification

Police-verified and identity-verified drivers.

## User Dashboard

View trips, bookings, fatigue alerts, and ride history.

## Driver Dashboard

Manage bookings, availability, earnings, and ratings.

## Firebase Authentication

Secure login and registration system.

## Responsive Design

Supports desktop, tablet, and mobile devices.
