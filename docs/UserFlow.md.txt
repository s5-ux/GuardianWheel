# GuardianWheel User Flow

## User Journey

1. User launches GuardianWheel.
2. User logs into the platform.
3. Driver monitoring starts automatically.
4. Camera captures facial landmarks.
5. EAR and PERCLOS are calculated continuously.
6. If fatigue is not detected:

   * Monitoring continues.
7. If fatigue is detected:

   * Alert is generated.
8. User receives a replacement driver recommendation.
9. User books a verified driver.
10. Driver is assigned.
11. Live GPS tracking starts.
12. Journey continues safely.

## Emergency Flow

1. User presses SOS button.
2. Emergency contact receives notification.
3. Current location is shared.
4. Support team is informed.
